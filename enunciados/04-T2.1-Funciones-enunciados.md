# Ejercicios · T2.1 - Funciones, arrow functions y parámetros por defecto

### Ejercicio 1 (básico) · Saludos

1. Escribe una **función con nombre** `getFullName(name, lastName)` que devuelva el nombre completo separado por un espacio.
2. Escribe una **arrow function** `greet(name, language = 'es')` que devuelva:
   - `'Hola, <name>'` si el idioma es `'es'`.
   - `'Hello, <name>'` si es `'en'`.
   - `'Bonjour, <name>'` si es `'fr'`.
   - El saludo en español para cualquier otro idioma.

| Llamada | Resultado |
|---|---|
| `getFullName('Godofredo', 'Pérez')` | `'Godofredo Pérez'` |
| `greet('Godofredo')` | `'Hola, Godofredo'` |
| `greet('Rodofasio', 'en')` | `'Hello, Rodofasio'` |
| `greet('Ruperto', 'fr')` | `'Bonjour, Ruperto'` |
| `greet('Gutufacio', 'de')` | `'Hola, Gutufacio'` |
| `greet(getFullName('Godofredo', 'Pérez'), 'en')` | `'Hello, Godofredo Pérez'` |

### Ejercicio 2 (medio) · Pagar a medias

1. `calculateTip(bill, percent = 10)` devuelve la propina redondeada a 2 decimales.
2. `splitBill(bill, people, percent = 10)` devuelve lo que paga cada persona, propina incluida, redondeado a 2 decimales. **Debe usar `calculateTip`.**

Para redondear a 2 decimales: `Math.round(numero * 100) / 100`.

| Llamada | Resultado |
|---|---|
| `calculateTip(45)` | `4.5` |
| `calculateTip(45, 15)` | `6.75` |
| `splitBill(45, 3)` | `16.5` |
| `splitBill(100, 3, 20)` | `40` |
| `splitBill(50, 3)` | `18.33` |

### Ejercicio 3 (reto) · Tiempo de lectura

Escribe `getReadingTime(text, wordsPerMinute = 200)`, que devuelva cuántos minutos se tarda en leer un texto, siempre redondeando hacia arriba (`Math.ceil`), con el formato `'X min de lectura'`.

- Supón que las palabras están separadas por un único espacio. Pista: `text.split(' ')` devuelve un array con las palabras y `.length` te dice cuántas hay.
- Si el texto está vacío o solo tiene espacios, devuelve `'0 min de lectura'`.

| Llamada | Resultado |
|---|---|
| `getReadingTime('Hola Godofredo')` | `'1 min de lectura'` |
| `getReadingTime(longText)` (450 palabras) | `'3 min de lectura'` |
| `getReadingTime(longText, 100)` | `'5 min de lectura'` |
| `getReadingTime('')` | `'0 min de lectura'` |
| `getReadingTime('   ')` | `'0 min de lectura'` |

Para crear `longText`: `const longText = 'palabra '.repeat(450).trim();`

Entrégala dos veces: como función con nombre y como arrow function.
