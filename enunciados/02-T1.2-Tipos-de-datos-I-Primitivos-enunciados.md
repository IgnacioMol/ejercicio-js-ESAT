# Ejercicios · T1.2 - Tipos de datos I · Primitivos

### Ejercicio 1 (básico) · ¿Qué saldrá por consola?

**Antes de ejecutar nada**, escribe en un comentario junto a cada línea qué crees que saldrá. Después ejecútalo y, en las que hayas fallado, añade un segundo comentario explicando por qué sale lo que sale.

```js
console.log(1 + '1');
console.log(typeof '42');
console.log(2 + 3 * 4);
console.log(17 % 5);
console.log('Godofredo'.length);
console.log(10 === '10');
console.log('Ornitorrinco'.toUpperCase().includes('RINCO'));
console.log(typeof (5 > 3));
console.log(`${2 + 2} manzanas`);
console.log(!(3 >= 3) || 'a' !== 'b');
```

### Ejercicio 2 (medio) · La ficha del libro

Con estas variables:

```js
const title = 'La venganza de Xindasvinto';
const author = 'Ruperto Gil';
const pages = 320;
const isRead = true;
```

Crea, **sin usar `if`**:

- `bookCard`: un string con comillas invertidas que dé exactamente `"La venganza de Xindasvinto" de Ruperto Gil · 320 páginas · Leído: true`.
- `isLongBook`: `true` si tiene más de 300 páginas.
- `hasRevengeInTitle`: `true` si el título contiene la palabra "venganza", escrita en mayúsculas o minúsculas.
- `titleLength`: el número de caracteres del título.

**Salida esperada** con `console.log(bookCard, isLongBook, hasRevengeInTitle, titleLength)`:

```
"La venganza de Xindasvinto" de Ruperto Gil · 320 páginas · Leído: true true true 26
```

### Ejercicio 3 (reto) · ¿Nombre de usuario válido?

Un nombre de usuario es válido si cumple **todas** estas reglas:

- Tiene entre 3 y 15 caracteres, ambos incluidos.
- No empieza por `_`.
- No contiene espacios.

Escribe una única expresión booleana, **sin `if`**, que calcule `isValidUsername` a partir de una variable `username`. Pruébala cambiando el valor de `username`:

| `username` | `isValidUsername` |
|---|---|
| `'godo'` | `true` |
| `'_rodofasio'` | `false` |
| `'gu'` | `false` |
| `'ruperto el grande'` | `false` |
| `'abc'` | `true` |
| `'xindasvinto_2025'` (16 caracteres) | `false` |
