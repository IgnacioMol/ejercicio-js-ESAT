# Ejercicios · T1.1 - Variables

### Ejercicio 1 (básico) · El perfil de Godofredo

Declara las variables necesarias para el perfil de Instagram de Godofredo, eligiendo `const` o `let` según si el valor cambia o no:

- Nombre de usuario: `godofredo_88`.
- Seguidores: 100.
- Publicaciones: 12.
- Si la cuenta es privada: no.

Después, simula lo que pasa durante el día cambiando los valores (sin escribir los números finales a mano):

1. Gana 3 seguidores.
2. Pierde 1 seguidor.
3. Publica una foto nueva.

Al final, muestra por consola:

```
godofredo_88 102 13
```

### Ejercicio 3 (reto) · Intercambiar estanterías

Tienes dos estanterías:

```js
let shelfA = 'Libros';
let shelfB = 'Discos';
```

1. Intercambia su contenido **sin volver a escribir** `'Libros'` ni `'Discos'`. Al final, `console.log(shelfA, shelfB)` debe mostrar `Discos Libros`.
2. Debajo, calcula el total de un carrito con variables: precio por unidad 12,5 €, 3 unidades y un descuento fijo de 5 €. Declara una variable para cada dato y para cada resultado intermedio.

**Salida esperada:**

```
Discos Libros
Subtotal: 37.5 €
Total: 32.5 €
```
